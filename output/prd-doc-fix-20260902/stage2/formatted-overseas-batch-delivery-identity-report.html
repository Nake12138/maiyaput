1. 项目背景与目标

1.1 项目背景

海外投放系统面向短剧出海投放场景，基于 TikTok Business API 管理广告投放基础设施。模板管理模块沉淀常用投放配置，其中 TikTok 账号包用于将多个 TikTok 账号组合为模板，供自动化任务快速引用；自动化任务模块支持按规则自动创建广告，投放身份（TikTok 账号）决定广告以哪些 TikTok 账号进行投放。系统提供「TikTok 账号包」与「手动选择」两种投放身份选择方式，并需兼容历史任务数据的回显。

1.2 文档目标

本文档定义批量投放模块中 TikTok 账号包与自动化任务投放身份的功能需求、交互逻辑、数据筛选、表格字段、数据权限与接口依赖，作为原型评审、研发排期与测试验收的依据。文档覆盖 5 个核心用户故事，明确每个表格的字段说明、数据来源与数据流转路径。

1.3 适用范围

  • 所属模块：海外投放系统 → 批量投放 → 模板管理 / 自动化任务
  • 页面文件：pages/overseas-template.html、pages/overseas-auto-delivery.html
  • 复用样式：styles/main.css、styles/prd.css、scripts/prd.js

3. 核心业务流程

3.1 流程概述

进入模板管理 - TikTok 账号包 Tab
  ├─→ 输入名称/选择创建人 → 点击「查询」过滤列表
  ├─→ 点击「新增TikTok 账号包」→ 打开新增抽屉
  ├─→ 点击某行「名称」→ 打开编辑抽屉查看详情
  ├─→ 点击某行「复制」→ 打开复制抽屉（名称前自动拼接「复制-」）
  ├─→ 点击某行「编辑」→ 打开编辑抽屉
  └─→ 点击某行「删除」→ 二次确认后删除（仅自己创建的数据可操作）

3.2 主流程步骤描述

  1. 用户进入模板管理页面，默认展示 TikTok 账号包 Tab 列表。
  2. 可按名称模糊查询、按创建人精确筛选，点击「查询」后执行过滤，点击「重置」清空条件并恢复全量列表。
  3. 列表中的「名称」为可点击链接，任何权限下均可点击打开编辑抽屉查看详情。
  4. 仅当前用户自己创建的数据，操作列的「复制」「编辑」「删除」按钮可点击；非本人数据按钮置灰不可点击。
  5. 点击「新增TikTok 账号包」打开右侧抽屉，名称、备注为空，已选区为空。
  6. 在抽屉内通过左右穿梭框选择账号，左侧勾选后自动移入右侧已选区，右侧删除后左侧自动取消勾选。
  7. 点击「确定」保存账号包并关闭抽屉；点击「取消」不保存并关闭抽屉。

3.3 流程概述

打开新建/编辑自动化任务抽屉
  └─→ 定位到「投放身份（TikTok 账号）」字段
        ├─→ 方式一：TikTok 账号包
        │      ├─→ 点击「选择TT账号包」打开弹窗
        │      ├─→ 勾选/取消勾选账号包（支持空选）
        │      └─→ 点击「确定」保存并展示已选账号包标签
        └─→ 方式二：手动选择
               ├─→ 点击触发按钮展开下拉多选
               ├─→ 勾选/取消勾选账号
               ├─→ 点击一键清除按钮清空全部已选
               └─→ 点击外部区域或按 Esc 收起下拉

5. 用户故事

5.1 US-001 TikTok 账号包列表查询与展示（P0）

故事描述：作为投放运营，我想要查看并按名称/创建人搜索 TikTok 账号包列表，以便快速定位目标账号包并在自动化任务中引用。数据权限按组织架构控制：组长可查看组员数据，组员仅可查看自己的数据；拥有「全部数据」权限的用户可查看全部数据。

筛选项（组件类型）

  • 名称：单行文本输入框（占位「请输入名称」）。
  • 创建人：下拉选择（占位「请选择创建人」）。
  • 「查询」/「重置」按钮；点击「查询」后按条件过滤，点击「重置」清空全部条件并恢复全量列表。

表格字段

  • 选择列：复选框，表头支持全选。
  • ID：数字。
  • 名称：文本，可点击链接，打开编辑抽屉；无论数据归属均可点击名称查看详情。
  • 备注：文本。
  • TikTok账号数量：数字。
  • 创建人：文本。
  • 创建时间：文本，格式 yyyy-MM-dd HH:mm。
  • 更新时间：文本，格式 yyyy-MM-dd HH:mm。
  • 操作：按钮组（复制、编辑、删除）；仅当前用户自己创建的数据展示可点击按钮，非本人数据按钮置灰不可点击。

数据来源

  • 模板管理-TikTok账号包列表数据 ← 后端接口返回。

数据流转

页面加载 → 调用「获取 TikTok 账号包列表」→ 渲染主表；用户在筛选栏输入名称或选择创建人后点击「查询」执行过滤；点击「重置」恢复全量；点击「新增TikTok 账号包」打开新增抽屉；点击名称链接打开编辑抽屉查看详情。

界面示意

验收标准

  1. 页面加载后默认展示 TikTok 账号包 Tab 列表。
  2. 支持按名称模糊查询与按创建人精确筛选，点击「查询」后才执行过滤。
  3. 名称列以链接形式展示，任何权限下均可点击打开编辑抽屉查看详情。
  4. 操作列提供「复制」「编辑」「删除」入口；仅本人创建的数据可操作，非本人数据按钮置灰不可点击。
  5. 表格下方提供分页条（总数、页码、每页条数、跳页）。

5.2 US-002 新增/编辑/复制 TikTok 账号包（P0）

故事描述：作为投放运营，我想要新建、编辑或复制 TikTok 账号包，以便将常用账号组合沉淀为模板，供自动化任务快速引用。

筛选项（组件类型）

  • 左侧待选区：
    • TT账号名称：单行文本输入框（占位「请输入TT账号名称」）。
    • 语言：下拉选择（占位「请选择语言」，枚举与短剧管理页面语言筛选项保持一致）。
    • 备注：单行文本输入框（占位「请输入备注」）。
    • 「查询」/「重置」按钮。
  • 右侧已选区：
    • TT账号名称、语言、备注筛选 +「查询」/「重置」按钮。
    • 工具条右侧显示「已选：N <清空>」。

表单与穿梭框字段

  • 名称：单行文本输入框，必填，占位「请输入」，限制 50 字符；复制时自动在名称前拼接「复制-」。
  • 备注：单行文本输入框，占位「请输入」，限制 100 字符。
  • TikTok 账号：左右穿梭框。
    • 左侧表格列：选择列（复选框，表头支持全选）、TikTok账号名称（头像 + 账号名称组合展示）、语言、备注。
    • 右侧表格列：TikTok账号名称（头像 + 账号名称组合展示）、语言、备注、操作（删除按钮）。

数据来源

  • 左侧待选 TikTok 账号列表 ← 资产管理-TikTok账号页面列表数据（接口返回）。
  • 右侧已选账号集合 ← 当前 TikTok 账号包维护的数据（新增时为空，编辑/复制时回显原包已选账号）。

数据流转

点击「新增/编辑/复制」→ 打开右侧宽抽屉（标题分别为「新增TikTok 账号包」「编辑TikTok 账号包」「复制TikTok 账号包」）→ 编辑时回显原名称、备注与已选账号，复制时名称前自动拼接「复制-」并回显原备注与已选账号 → 用户在左侧筛选并勾选账号 → 勾选账号自动移入右侧已选区 → 在右侧点击「删除」后，左侧对应账号自动取消勾选 → 点击「确定」保存账号包并关闭抽屉。

界面示意

验收标准

  1. 新增时名称与备注为空，已选区为空。
  2. 编辑时回显原包名称、备注与已选账号；复制时名称前自动拼接「复制-」，备注与已选账号回显原包数据。
  3. 名称必填，最长 50 字符；备注可选，最长 100 字符。
  4. 左侧账号列表样式与资产管理-TikTok账号页一致（头像 + 账号名），不含更新人/更新时间/操作字段。
  5. 左侧勾选账号后，该账号立即出现在右侧已选区；右侧删除账号后，左侧对应复选框自动取消勾选。
  6. 左侧表头全选/半选仅对当前过滤后的可见行生效。
  7. 右侧已选区支持按名称、语言、备注筛选，并显示「已选：N」与「清空」链接。
  8. 点击「确定」保存并关闭抽屉；点击「取消」不保存并关闭抽屉。

5.3 US-003 投放身份（TikTok 账号）模式切换与回显（P0）

故事描述：作为投放运营，我想要在创建/编辑自动化任务时选择投放身份方式，并正确回显历史任务的投放身份数据。历史任务中已保存的投放身份统一按「手动选择」模式处理，并正常回显用户已选选项。

交互控件

  • 投放身份（TikTok 账号）分段选择器：选项为「TikTok 账号包」/「手动选择」。
  • TikTok 账号包模式下显示「选择TT账号包」按钮与已选账号包标签。
  • 手动选择模式下显示下拉多选框（支持搜索、一键清除）与已选账号标签。

数据来源

  • TikTok 账号包列表 ← 模板管理-TikTok账号包页面列表数据。
  • 手动选择账号列表 ← 资产管理-TikTok账号列表数据。

数据流转

新建任务默认选中「TikTok 账号包」模式；用户点击分段项切换模式；选择账号包模式时点击「选择TT账号包」打开弹窗多选；手动选择模式时点击下拉勾选账号，点击一键清除按钮可清空全部已选项；编辑/复制历史任务时，历史投放身份数据统一按「手动选择」模式处理，并回显用户已选账号。

界面示意

验收标准

  1. 投放身份字段标题为「投放身份（TikTok 账号）」。
  2. 默认选中「TikTok 账号包」模式。
  3. 切换模式时下方展示对应选择控件，已选结果互不影响。
  4. 历史任务（编辑/复制）统一按手动选择模式回显已选账号。
  5. 手动选择模式下提供一键清除全部已选项功能。

5.4 US-004 TikTok 账号包选择弹窗（P0）

故事描述：作为投放运营，我想要从已有的 TikTok 账号包中选择多个包作为投放身份，以便批量使用沉淀好的账号组合。

筛选项（组件类型）

  • 名称：单行文本输入框（占位「请输入名称」）+「查询」/「重置」按钮；点击「查询」后按名称过滤，点击「重置」恢复全量列表。

表格字段

  • 选择列：复选框，表头支持全选。
  • 名称：文本。
  • TikTok账号数量：数字。
  • 备注：文本。

数据来源

  • 模板管理-TikTok账号包页面列表数据。

数据流转

点击「选择TT账号包」打开弹窗 → 渲染账号包列表并回显已选项 → 用户勾选/取消勾选 → 底部显示已选数量 → 点击「确定」保存当前选择（允许空选）并关闭弹窗，在抽屉内展示已选账号包标签 → 点击「取消」不保存并关闭。

界面示意

验收标准

  1. 弹窗标题为「选择TikTok账号包」。
  2. 支持按账号包名称模糊查询。
  3. 列表支持多选，表头全选仅对当前过滤结果生效。
  4. 底部实时显示已选数量。
  5. 未选择任何数据时点击「确定」仍可保存（即允许清空已选）。
  6. 点击「确定」后已选账号包以标签形式展示在抽屉内。
  7. 点击标签上的移除按钮可取消选择。

5.5 US-005 手动选择 TikTok 账号（P0）

故事描述：作为投放运营，我想要手动从全部 TikTok 账号中多选具体账号作为投放身份，并支持一键清除全部已选项。

筛选项（组件类型）

  • 下拉面板顶部搜索框：单行文本输入框（占位「请输入名称」，输入时实时过滤下拉选项）。

下拉与已选展示

  • 触发按钮：显示当前已选数量或默认占位「请选择TikTok账号」。
  • 一键清除按钮：×，点击后清空全部已选项。
  • 下拉选项：复选框 + 账号名称 + 语言。
  • 已选标签：账号名称（语言）+ 移除按钮。

数据来源

  • 资产管理-TikTok账号列表数据。

数据流转

点击触发按钮展开下拉面板 → 展示全部可选项并回显已选状态 → 输入关键词实时过滤 → 勾选/取消勾选更新已选账号标签与触发按钮文案 → 点击一键清除按钮清空全部已选项 → 点击面板外部或按 Esc 收起下拉。

界面示意

验收标准

  1. 下拉框展示全部可选项，并按名称/语言实时过滤。
  2. 已选账号以标签形式展示在触发按钮下方。
  3. 点击标签上的移除按钮可取消对应账号选择。
  4. 点击一键清除按钮可一次性清空所有已选账号。
  5. 点击下拉外部区域或按 Esc 收起下拉面板。

6. 数据权限

7. 历史数据处理

7.1 历史数据处理

对于早期已创建的自动化任务，其投放身份数据统一按「手动选择」模式处理。编辑或复制历史任务时，系统按手动选择模式回显用户已选的 TikTok 账号，不强制切换为账号包模式。

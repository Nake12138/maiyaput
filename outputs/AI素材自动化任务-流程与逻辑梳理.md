# AI素材自动化任务 · 流程与逻辑梳理（核对稿）

> 用途：供需求评审 / PRD 校对。内容基于当前原型实现（`maiyaput/index.html`）+ 历次沟通确认的规则整理。
> 标注 **⚠** 的条目为原型或规则中尚未定义，需业务确认；标注 **?** 的为我的推断，需你拍板。

## 一、模块定位与对象关系

- 入口：推广管理 → AI素材推广 → 自动化任务
- 四个页签：**任务 / 短剧任务 / 标准投放 / 全域投放**
- 对象层级：**任务（1）→ 短剧任务（N）→ 投放基建（账户 → 项目 → 单元 → 创意）**

| 对象 | 说明 | 当前列表字段 |
|---|---|---|
| 任务 | 用户创建的自动化投放配置主体 | ID、任务、短剧数量、创建人、创建时间、操作（编辑 / 日志） |
| 短剧任务 | 任务命中的每部短剧自动生成的一条执行记录 | ID、开关、短剧（含短剧ID）、所属任务、测出状态、AI素材、素材更新时间、最近一次执行时间（标准）、最近一次执行时间（全域）、操作（日志） |
| 投放基建 | 按任务配置生成的账户 / 项目 / 单元 / 创意 | 标准投放、全域投放页签按层级逐级下钻查看 |

## 二、任务配置（新增任务抽屉）

| 模块 | 配置项 |
|---|---|
| 短剧范围（三页签共用） | 短剧标签 / 剧名 + 包含 / 不包含 + 取值；支持添加多组 |
| 标准投放 | 4 个子模式，每个可单独开关「启用该模式投放」：<br>稳定成本-付费、稳定成本-IAA、最大转化-付费、最大转化-IAA |
| └ 基建数量/单剧 | 投放账户数\*、账户下项目数\*（默认 1）、项目下单元数（默认 3）、单元下创意数（默认 30）、素材重复次数（不限 / 自定义，默认 1） |
| └ 投放配置 | ROI系数（付费模式选填，填了则深度优化目标为付费ROI；IAA 模式必填）、出价\*、日预算\* |
| └ 项目排期 | 开投时间（今天 / 明天）、投放天数（不限 / 指定天数）、投放时段（不限 / 指定时间段） |
| 全域投放 | 投放配置 + 项目排期（**无**基建数量，属推送已有基建） |
| 控损管理 | **⚠ 原型为「待补充」占位，字段未定义**——而它是测出 / 未测出的判定依据 |

**⚠ 缺失项**：任务的「运行间隔」仅在修改日志示例中出现（180分钟 → 30分钟），**新增任务抽屉里没有对应配置入口**，需确认该字段是否已下线、还是漏做。

## 三、生命周期（5 阶段）

1. **创建任务**：配置短剧范围、投放模式与基建、项目排期、控损规则
2. **任务按运行间隔执行**：命中的短剧被打上投放标签 → 生成「短剧任务」，开关默认开启
3. **判定 AI素材数量**：≥ 90 → 测试中（开始 3 天测试期）；< 90 → 待测试
4. **3 天测试期投放**：按任务配置搭建基建（账户 → 项目 → 单元 → 创意）并投放，即「短剧测试」
5. **控损判定回写**：测试期内达标 → 测出；到期未达标 → 未测出；测试期内用户手动关闭开关且未达标 → 未测出

终局：
- **测出**：开关保持开启时，后续新素材按任务配置持续投放
- **未测出**：停止投放、开关锁死为关闭、自动取消该短剧的白名单标签

## 四、测出状态机

| 状态 | 样式 | 进入条件 | 开关默认值 | 含义 |
|---|---|---|---|---|
| 待测试 | 蓝色 | 打上投放标签时 AI素材 **< 90** | 开启 | 素材不足，暂不进入测试 |
| 测试中 | 橙色 | 打上投放标签时 AI素材 **≥ 90**；或待测试状态下素材累积达到 **90** | 开启 | 已进入 3 天测试期 |
| 测出 | 绿色 | 3 天测试期内控损结果达标 | 开启 | 通过测试，可持续投放新素材 |
| 未测出 | 灰色 | 3 天测试期结束仍未达标；或测试期内用户关闭开关且未达标 | 关闭（锁定） | 终态，停投 + 取消白名单标签 |

流转关系：

```
                ┌────────── 素材累积达 90 ──────────┐
                ↓                                    │
开启短剧任务 → [待测试] ──── 素材 ≥ 90 ────→ [测试中] ── 3天内达标 ──→ [测出] ─┐
  素材 <90                                     │                          │
                                       3天到期未达标                   素材更新
                                     / 用户关开关未达标                    │
                                               ↓                        ↓
                                          [未测出]（终态）        继续按配置投放新素材
```

## 五、开关规则（短剧任务是否继续执行）

开关含义：控制该短剧任务是否继续执行，继续执行 = **短剧测试 + 新素材投放**。

| 当前状态 | 关闭开关后 | 是否支持再开启 |
|---|---|---|
| 测出 | 状态仍为「测出」，但后续产生的新素材**不投放** | 支持 |
| 待测试 | 状态仍为「待测试」 | 支持 |
| 测试中 | 状态改为「未测出」，开关锁死 | **不支持** |
| 未测出 | 已为关闭态，不可操作 | **不支持** |

**投放的唯一成立条件**：开关 = 开启 **且** 测出状态 = 测出。状态非「测出」时，无论是否产生新素材，均不投放。

## 六、修改日志规则（操作人 / 更新时间 / 变更内容）

**仅「用户手动关闭短剧任务」场景操作人为对应用户，其余场景操作人一律为「系统」。**

| # | 场景 | 变更内容 | 操作人 |
|---|---|---|---|
| 1 | 短剧打上投放标签（任务开启） | `开启短剧任务，AI素材数量：{xx}，大于/小于90。短剧任务测出状态：{测试中/待测试}` | 系统 |
| 2 | 测试期内判定回写 | `测试期内判定回写。短剧任务测出状态：{测出/未测出}` | 系统 |
| 3-a | 3 天测试期结束仍未达标 | `3 天测试期结束未达标。短剧任务测出状态：未测出` | 系统 |
| 3-b | 3 天内用户关闭开关且未达标 | `用户手动关闭短剧任务。短剧任务测出状态：未测出` | **对应用户** |
| 4 | 测出后素材更新 | `素材更新，新增素材数量：{xx}` | 系统 |

**⚠ 补充场景（上一轮新增，未在你原始清单内）**：待测试 → 测试中的自动流转，建议变更内容为
`AI素材数量更新为：{xx}，大于等于90。短剧任务测出状态：测试中`，操作人：系统。

## 七、待确认清单（按优先级）

### P0 — 影响能否上线

| # | 问题 | 现状与风险 | 建议 |
|---|---|---|---|
| A1 | 未测出不可逆，一条短剧只能测一次 | 测试中手动关闭 → 未测出 → 开关永久锁死；控损未达标同样锁死。素材是持续累积的 | 补回流路径（如「重新测试」），并说明谁能解锁 |
| A2 | 未测出时「取消白名单标签」没说要不要停投在跑的计划 | 只取消标签，已建基建上的在跑广告仍在花钱，控损目的落空 | 明确是否同步关停在投计划、清理已建基建 |
| A3 | 关闭期间产生的新素材，重新开启后补不补投 | 测出 + 关闭 30 天，期间新增 50 条素材 | 建议「不回溯」，只投开启后新增 |
| A4 | 控损管理配置字段为空 | 原型为占位，而它是测出 / 未测出的判定依据 | 补齐字段（如消耗门槛、ROI 门槛、判定周期） |
| A5 | 「运行间隔」无配置入口 | 仅出现在修改日志示例里 | 确认是漏做还是已下线 |

### P1 — 影响体验与一致性

| # | 问题 | 建议 |
|---|---|---|
| B1 | 待测试 + 关闭时，状态冻结与素材增长矛盾 | 明确关闭期间是否继续跑判定、是否冻结状态与素材统计 |
| B2 | 测出 + 关闭时列表仍显示绿色「测出」，易误判 | 建议关闭时行级灰化或加「已停止投放」标识 |
| B3 | 「新素材」判定口径未定义 | 明确按素材数增量，还是按「素材更新时间」晚于「最近一次执行时间」 |
| B4 | 父子层级冲突未定义 | 上层任务停用 / 删除 / 改配置时，其下短剧开关如何处理（建议父关则子全关且禁用） |
| B5 | 任务配置变更后，已测出的短剧按新配置还是旧配置投放 | 需明确 |
| B6 | 「投放标签」与「白名单标签」是否同一概念 | 场景 1 说打「投放标签」，未测出时取消「白名单标签」，原型两处文案并存 |
| B7 | 全域投放与标准投放的关系 | 全域是独立并行投放，还是标准的补充？测出后是否同时投标准 + 全域？ |

### P2 — 边界情况

| # | 问题 | 建议 |
|---|---|---|
| C1 | 初始态缺失 | 任务刚创建、尚未执行时列表显示什么？补「待执行 / 未开始」态 |
| C2 | 测试中期间素材跌破 90 | 继续测还是转待测试？ |
| C3 | 3 天测试期是否按自然日计算、跨任务执行如何处理 | 明确起算点与结束判定 |
| C4 | 原型示例数据不一致 | 短剧1 列表 AI素材 = 125，但「短剧数量弹框」仍为 90，需同步 |

### 措辞修正建议

开关含义写的是「继续执行 = 短剧测试 + 新素材投放」，但**测出**状态已无测试环节、只有新素材投放。建议描述上区分，避免开发理解成测出状态仍在跑测试。

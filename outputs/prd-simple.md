# 商务中心页面 PRD（简洁版）

> **原型来源**：`pages/overseas-bc.html`（海外投放系统 → 账号管理 → 商务中心）  
> **版本**：v2.2-simple ｜ **说明**：聚焦用户故事与验收标准，接口细节见文末官方文档链接

---

## 1. 背景与目标

海外投放系统基于 TikTok Business API 管理广告投放基础设施。商务中心（BC）是核心组织单元，本页面采用「左侧商务中心单选面板 + 右侧 BC用户 / TikTok账号 双页签」结构，承载 BC 切换、BC用户管理、TikTok 账号资产查看与权限分配。

**目标**：投放运营在一个页面完成「选 BC → 看 BC用户 / 账号 → 分配/撤销/添加 TikTok 账号」全流程。

## 2. 用户故事与验收标准

> 按实施顺序排列（数据源 → 展示 → 交互），优先级均为 P0。

### US-001 商务中心列表展示与单选（P0）

作为投放运营，我想要在左侧查看商务中心列表并单选目标 BC，以便切换查看该 BC 下的 BC用户和 TikTok 账号。

**验收标准**

- [ ] 左侧展示「商务中心」面板：单选指示符 / 商务中心名称 / `N 人 · N TT账号`
- [ ] 支持按名称即时模糊搜索（包含匹配、不区分大小写），无结果显示「暂无数据」
- [ ] 单选语义：同一时间仅一个 BC 选中，点击行即切换；默认选中第一个 BC
- [ ] 切换选中后右侧两个页签同步刷新；列表数据每 30 分钟自动轮询刷新

### US-002 BC用户列表页签与搜索（P0）

作为投放运营，我想要查看当前所选 BC 下的 BC用户列表并搜索 BC用户，以便定位目标 BC用户。

**验收标准**

- [ ] 右侧默认显示「BC用户」页签；支持按 BC用户名搜索（「查询」或回车执行，「重置」恢复全量）
- [ ] 表格列序：选择 / BC用户名 / TikTok 账号（数字链接）/ 所属商务中心 / 操作（分配 TikTok 账号）
- [ ] 工具条：左侧「已选择 X 个BC用户」+「分配TikTok」；右侧「上次更新 HH:MM:SS」独立时间戳
- [ ] 顶部「刷新」：置灰「刷新中…」→ 重新拉取 → 恢复并更新时间戳

### US-003 单个 BC用户分配 TikTok 账号（P0）

作为投放运营，我想要为单个 BC用户分配 TikTok 账号，以便授予其投放资产权限。

**验收标准**

- [ ] 行内「分配 TikTok 账号」打开弹框，标题：`分配 TikTok 账号 - {BC用户名}`
- [ ] 弹框筛选项仅 TT账号名称 + 查询 / 重置
- [ ] 表格列序：选择 / TikTok 账号（账号名称）/ 更新人 / 更新时间；已分配账号禁用并标注「已分配」，全选自动跳过
- [ ] 未勾选可用账号时点「确定」→ 提示「请至少选择一个未分配的 TikTok 账号」

### US-004 BC用户已分配 TikTok 账号抽屉（P0）

作为投放运营，我想要查看某个 BC用户已分配的 TikTok 账号明细，以便确认其资产权限。

**验收标准**

- [ ] 点击行内「TikTok 账号」数量打开宽抽屉，标题：`TikTok 账号 - {BC用户名}（{BC名称}）`
- [ ] 仅列出该 BC用户已分配的账号；筛选项仅 TT账号名称 + 查询 / 重置
- [ ] 表格列序：选择 / TikTok账号名称 / 更新人 / 更新时间 / 操作（删除）
- [ ] 单条「删除」二次确认「是否取消授权该BC用户该 TikTok 账号？」后调用撤销接口
- [ ] 工具条：表格上方「已选择 X 个 TikTok 账号」+ 红色「批量删除」（勾选为空置灰）

### US-005 批量分配 TikTok 账号（P0）

作为投放运营，我想要勾选多个 BC用户后批量分配 TikTok 账号，以便提高分配效率。

**验收标准**

- [ ] BC用户页签勾选 N 个（表头全选支持半选），未勾选时「分配TikTok」置灰
- [ ] 弹框顶部提示「已选择 N 个BC用户，请勾选要分配的 TikTok 账号」
- [ ] 弹框筛选项仅 TT账号名称 + 查询 / 重置
- [ ] 表格列序：选择 / TikTok账号名称 / 更新人 / 更新时间；不展示「已分配」状态（后端自动判断）
- [ ] 未勾选账号时点「确定」→ 提示「请至少选择一个 TikTok 账号」

### US-006 TikTok 账号列表页签与搜索（P0）

作为投放运营，我想要查看当前所选 BC 下的 TikTok 账号资产明细，以便了解资产情况。

**验收标准**

- [ ] 「TikTok账号」页签展示当前 BC 全部账号；筛选项仅 TT账号名称 + 查询 / 重置 / 刷新 / 添加 TikTok 账号
- [ ] 表格列序：TikTok账号名称 / 已分配 BC 用户 / 所属商务中心 / 更新人 / 更新时间（无操作列）
- [ ] 「已分配 BC 用户」列显示数量，鼠标悬浮逐行展示 BC 用户名清单，未分配显示 0
- [ ] 「所属商务中心」固定在「TikTok账号名称」之后，取值恒为当前所选 BC 名称
- [ ] 独立时间戳「上次更新 HH:MM:SS」，与 BC用户页签互不干扰

### US-008 添加 TikTok 账号（关联方式）（P0）

作为投放运营，我想要通过扫码关联已有 TikTok 账号，以便复用已有资产。

**验收标准**

- [ ] 默认选中「关联 TikTok 账号」卡片，二维码区域直接展开
- [ ] 展示：二维码 + 「请使用 TikTok App 扫描二维码完成账号授权」+ 授权对象 {BC名称} + 「刷新二维码」按钮
- [ ] 提示「授权完成后弹框不会自动关闭；如二维码失效，可点击『刷新二维码』」
- [ ] 「刷新二维码」点击后置灰「刷新中…」重新拉取授权链接，完成后恢复
- [ ] 底部为「关闭」按钮，弹框仅由用户主动关闭

### US-009 BC用户已分配 TikTok 账号批量删除（P0）

作为投放运营，我想要在抽屉内一次性勾选多个 TikTok 账号并批量取消授权，以便快速收回资产权限。

**验收标准**

- [ ] 抽屉内首列复选框 + 表头全选（半选态）；工具条实时显示「已选择 X 个 TikTok 账号」
- [ ] 未勾选时红色「批量删除」置灰；点击后二次确认仅问「是否确认取消授权？」，明细显示 BC用户与总数
- [ ] 确认后串行调用「撤销用户对资产的权限」，完成后一次性刷新抽屉与 BC用户列表
- [ ] 成功提示「已批量取消授权 N 个 TikTok 账号：{账号名清单}」（账号名以「、」分隔），并清空勾选

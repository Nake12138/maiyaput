## 1. 文档背景

### 1.1 项目背景
海外投放系统面向短剧出海投放场景，基于 TikTok Business API 管理广告投放基础设施。商务中心（Business Center，下称 BC）是 TikTok 广告投放的核心组织单元，承载成员（用户）管理、TikTok 账号资产管理与权限分配。

### 1.2 文档目的
定义商务中心页面的功能需求、交互逻辑与接口依赖，作为原型评审、研发排期与测试验收的依据。接口文档细节本次暂不展开，仅提供官方文档链接供研发对照。

### 1.3 适用范围
- 所属模块：海外投放系统 → 账号管理 → 商务中心
- 页面文件：`pages/overseas-bc.html`
- 复用样式：`styles/main.css`、`scripts/main.js`

## 3. 核心业务流程

### 3.1 流程概述

```
查询商务中心列表
  ├─→ 点击「用户数量」→ 打开用户列表抽屉
  │      ├─→ 点击「TikTok 账号」数量 → 叠加打开 TikTok 账号列表抽屉（关闭后回到用户列表）
  │      ├─→ 行内「分配 TikTok 账号」→ 单用户分配弹框（多选，已分配禁选）
  │      └─→ 勾选用户 → 「分配TikTok」→ 批量分配弹框（多选，不区分已分配）
  ├─→ 点击「TikTok 账号」→ 打开 TikTok 账号列表抽屉
  ├─→ 点击「添加 TikTok 账号」→ 添加弹框（选择新建/关联，字段在弹框内展开）
  └─→ 点击「刷新」→ 重新拉取并渲染当前列表
```

### 3.2 主流程步骤描述
1. 用户进入商务中心页面，默认加载并展示商务中心列表（原型为 3 条示例数据）。
2. 可按商务中心名称筛选后查询/重置。
3. 点击某行「用户数量」，右侧抽屉展示该 BC 的成员列表。
4. 在用户列表中可搜索、勾选用户，进行单用户或批量分配 TikTok 账号。
5. 点击「TikTok 账号」数量，叠加查看该 BC 的 TikTok 账号资产列表。
6. 通过操作列「添加 TikTok 账号」为该 BC 新建或关联 TikTok 账号。
7. 通过「刷新」重新同步该 BC 数据。

## 5. 功能说明

### 5.1 F-001 商务中心列表查询

**基本事件流**
1. 用户在筛选栏输入商务中心名称关键字。
2. 点击「查询」→ 按名称过滤并展示列表。
3. 点击「重置」→ 清空筛选输入，恢复默认列表。

**需求规则**
- 查询条件：商务中心名称，模糊匹配。
- 重置仅清空本页筛选输入，不触发重新加载以外的额外动作。

**代码溯源**：`pages/overseas-bc.html` 筛选栏（第 156–165 行）、`searchBC()`/`resetBCFilter()`（第 848–852 行）

### 5.2 F-002 商务中心主表展示

**基本事件流**
1. 页面加载后渲染商务中心列表（数据驱动，原型数据源 `bcListData`）。
2. 表格列：商务中心名称 / 用户数量 / TikTok 账号 / 操作。
3. 「用户数量」「TikTok 账号」为链接样式，点击分别打开对应抽屉。
4. 操作列提供「添加 TikTok 账号」「刷新」两个链接。

**需求规则**
- 列宽固定（colgroup：32% / 15% / 15% / 38%），表头与列对齐。
- 用户数量、TikTok 账号数量与各自抽屉内列表条数一致（原型数据：1001 → 6 用户/3 账号，1002 → 4 用户/2 账号，1003 → 3 用户/2 账号）。
- 分页区：显示总条数、上一页/下一页、页码、每页条数（10/20/50 条/页）、跳页输入。原型为静态展示。

**代码溯源**：`pages/overseas-bc.html` 主表（第 167–204 行）、`bcListData`（第 837–841 行）、`renderBcList()`（第 855–869 行）

### 5.3 F-003 打开用户列表抽屉

**基本事件流**
1. 点击主表「用户数量」链接。
2. 右侧弹出用户列表抽屉（窄版，约 720px）。
3. 抽屉标题：`用户列表 - {商务中心名称}（{用户数}）`。
4. 加载该 BC 下成员列表，按用户名展示；勾选状态重置为空。

**需求规则**
- 每次打开抽屉重置：搜索关键字清空、批量勾选清空。
- 抽屉关闭后，主表状态不变。

**代码溯源**：`pages/overseas-bc.html` 抽屉（第 241–279 行）、`openBcUserDrawer()`（第 877–886 行）

### 5.4 F-004 用户列表搜索

**基本事件流**
1. 在用户列表抽屉顶部输入用户名关键字。
2. 输入即触发实时过滤（`oninput`），仅展示匹配用户。

**需求规则**
- 匹配方式：用户名包含关键字（不区分大小写）。
- 无匹配时表格显示「暂无数据」空态。
- 过滤不影响已勾选用户的选中状态（`batchSelectedUsers` 独立于可见列表）。

**代码溯源**：`pages/overseas-bc.html` 搜索框（第 250–252 行）、`renderBcUserList()`（第 893–916 行）

### 5.5 F-005 单用户分配 TikTok 账号

**基本事件流**
1. 用户列表中点击行内「分配 TikTok 账号」。
2. 弹出分配弹框（居中，520px），标题：`分配 TikTok 账号 - {用户名}`。
3. 弹框内列出该 BC 下全部 TikTok 账号（头像 + 账号名 + handle + 语言），支持按名称搜索、表头全选。
4. 勾选未分配账号 → 点击「确定」→ 提示分配结果并关闭弹框。

**备选事件流**
- 已分配给该用户的账号：复选框为选中且禁用（disabled）+「已分配」标签，不可取消勾选；表头全选自动跳过禁用项。
- 未勾选任何可用账号时点「确定」→ 提示「请至少选择一个未分配的 TikTok 账号」并中止。

**需求规则**
- 弹框 z-index（1200/1201）高于用户列表抽屉，叠加在抽屉之上显示。
- 关闭弹框（×/取消/遮罩）不影响底层用户列表抽屉（`stopPropagation` 防止误关）。
- 提交提示：`已为「{用户}」分配 N 个 TikTok 账号：{名称列表}`。
- 已分配数据源：`bcUserAssignedTt`（BC → 用户 → 账号数组）。

**关联功能点**：⬅ F-002（进入路径）、➡ F-006（同一账号分配数据源）、➡ F-007（账号资产数据源一致）

**代码溯源**：`pages/overseas-bc.html` 弹框（第 207–239 行）、`openAssignTtModal()` 等（第 918–970 行）

### 5.6 F-006 批量分配 TikTok 账号

**基本事件流**
1. 用户列表首列勾选一个或多个用户（表头全选支持半选态）。
2. 工具条实时显示「已选择 X 个用户」；无勾选时「分配TikTok」按钮置灰。
3. 点击「分配TikTok」→ 弹出批量分配弹框（520px）。
4. 弹框顶部提示：`已选择 N 个用户，请勾选要分配的 TikTok 账号：`。
5. 勾选账号（支持搜索、全选）→ 点击「确定」→ 提示批量分配结果并关闭。

**需求规则**
- 勾选状态在搜索、重渲染后保留；打开抽屉时重置。
- 批量分配弹框第一列**固定显示复选框**，不区分/不展示「已分配」状态——批量场景下各用户已分配情况不一，是否已分配由**后端自动判断**。
- 未勾选任何账号时点「确定」→ 提示「请至少选择一个 TikTok 账号」。
- 提交提示：`已为 N 个用户分配 M 个 TikTok 账号：{名称列表}`。
- 关闭弹框不影响底层用户列表抽屉。

**关联功能点**：⬅ F-004（勾选范围）、⬅ F-005（共享账号数据源）、➡ 接口「将资产分配给用户」

**代码溯源**：`pages/overseas-bc.html` 弹框（第 281–314 行）、工具条（第 253–258 行）、`batchSelectedUsers` 及批量函数（第 972–1049 行）

### 5.7 F-007 查看 TikTok 账号列表

**基本事件流**
1. 点击主表「TikTok 账号」数量，或用户列表行内「TikTok 账号」数量。
2. 右侧弹出 TikTok 账号列表抽屉（宽版），标题：`TikTok 账号列表 - {商务中心名称}（{数量}）`。
3. 表格字段：TikTok账号名称（头像 + handle）/ 语言 / 备注 / 更新人 / 更新时间，**无操作列**。

**需求规则**
- 从用户列表行内进入时，抽屉**叠加**在用户列表抽屉之上（DOM 顺序在后自然覆盖）；关闭 TikTok 账号列表后回到用户列表。
- 账号名称展示复用 `.tt-account-info` 样式（圆形头像 + 名称 + handle 两行布局），头像颜色由名称哈希确定性生成。
- 无匹配时显示「暂无数据」空态。

**关联功能点**：⬅ F-002 / F-003（进入路径）、➡ F-005 / F-006（账号数据源一致）

**代码溯源**：`pages/overseas-bc.html` 抽屉（第 316–349 行）、`renderTtAccountCell()`（第 1062–1071 行）、`openBcTtDrawer()`（第 1073–1081 行）

### 5.9 F-009 添加 TikTok 账号（新建方式）

**基本事件流**
1. 点击主表操作列「添加 TikTok 账号」→ 弹出添加弹框（520px）。
2. 商务中心名称自动带入且**不可编辑**（disabled）。
3. 添加方式为左右并排两个选项卡片：「新建 TikTok 账号」「关联 TikTok 账号」。
4. 选择「新建 TikTok 账号」→ 卡片高亮（蓝色边框 + 浅蓝底 + 右上角 ✓），弹框下方虚线分隔区展开新建字段：
   - TikTok账号名称（必填，占位「请输入TikTok账号名称」）
   - 头像（必填，点击上传、本地预览、可清除）
   - 国家/地区（必选，下拉 20 个选项）
5. 点击「确定」→ 依次校验名称/头像/地区 → 提示 `创建成功：{名称}（{商务中心} / {地区}）` → 关闭弹框。

**备选事件流**
- 校验不通过时分别提示：`请输入TikTok账号名称` / `请上传头像` / `请选择国家/地区`。
- 未选择添加方式时，底部仅显示「取消」按钮，「确定」不可见。
- 可随时切换添加方式，字段区随之切换。

**需求规则**
- 每次打开弹框重置：添加方式未选、字段清空、头像清空、按钮恢复初始态。
- 国家/地区选项：中国大陆、中国香港、中国台湾、美国、英国、日本、韩国、新加坡、马来西亚、泰国、印尼、菲律宾、越南、巴西、德国、法国、意大利、葡萄牙、澳大利亚、加拿大。

**关联功能点**：⬅ F-002（进入路径）、➡ 接口「在商务中心创建Tiktok账号」

**代码溯源**：`pages/overseas-bc.html` 弹框（第 351–445 行）、`openAddTtModal()`/`selectAddTtMode()`/`submitAddTtNew()`（第 1146–1222 行）

### 5.10 F-010 添加 TikTok 账号（关联方式）

## 7. 安全需求

### 7.1 权限控制
- 商务中心成员仅能查看/操作其有权限的商务中心及资产；资产分配、账号添加等写操作需校验操作者权限。
- 商务中心名称字段在添加弹框中禁用编辑，由后端基于当前操作上下文注入，防止越权填写。

### 7.2 数据校验
- 新建 TikTok 账号：名称非空、头像必传、国家/地区必选，提交前前端校验，后端二次校验。
- 分配操作：至少选择一个账号；批量分配时是否已分配由后端自动判断，避免前端状态不一致。

### 7.3 输入防护
- 搜索关键字仅作本地过滤展示，不携带权限信息；提交类请求需对输入做长度与注入防护。
